# eagle-image-combiner-plugin

ローカル画像をドラッグ＆ドロップし、横・縦・2列に結合してEagleへ登録するプラグインです。

## 機能

- ローカル画像ファイルをドラッグ＆ドロップで追加
- 横並び、縦並び、2列並びで結合
- 境界線の有無、太さ、黒/白を指定
- 先頭画像名を手がかりにEagle内アイテムを検索
- 見つかった場合、URL、注釈、所属フォルダを結合画像へ引き継ぎ
- 結合画像をJPEGとしてEagleへ追加

## 使い方

1. このプラグインをEagle内で起動します。
2. 画像ファイルをドロップエリアにドラッグ＆ドロップします。
3. 並べ方と境界線を調整します。
4. `結合してEagleに追加` を押します。

## 開発メモ

Python版 `testname.py` の挙動を、Eagle Plugin API とブラウザCanvasで再実装しています。
ファイル保存先の指定は廃止し、`eagle.item.addFromBase64()` でEagleへ直接追加します。
